# Auth OIDC (Plan B of 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Depends on:** Plan A (`2026-07-21-auth-core.md`) merged — this plan builds on
`hub/internal/auth` (`Service`, `Identity`, `Grant`), the auth middleware, the
login UI and the `storage.Store` auth methods it introduced. Do not start until
Plan A is on `main`.

**Goal:** Add OIDC (authorization-code + PKCE) as a second login method behind
the same server-side session, with IdP group→grant mapping, so Keycloak / Entra
/ Okta / Google / Dex users sign in and land in the exact same `Identity` a
local user gets — per the accepted AEP `design/2026-07-21-auth-oidc-rbac.md`.

**Architecture:** A new `oidc` provider in `hub/internal/auth` performs discovery
+ code exchange + ID-token verification and returns claims. `auth.Service` grows
`CompleteSSO` (upsert the SSO user, store their IdP groups, mint the same session
as local login). Group→grant mapping is a **pure, hot-reloadable** function:
manual grants stay untouched in `auth_grant`; the mapped grants are computed
in-memory in `identityFor` from the user's stored groups + the current mapping,
so a mapping edit takes effect on the next request (a superset of the AEP's
"recompute at each SSO login"). Config is a mounted YAML file loaded through the
existing poll-swap reloader (`hub/cmd/hub/alerting.go` pattern). The SPA login
page renders an SSO button from `/api/v1/auth/config`.

**Tech Stack:** Go 1.26, `github.com/coreos/go-oidc/v3/oidc` (discovery + ID-token
verify), `golang.org/x/oauth2` (code exchange, built-in PKCE via
`GenerateVerifier`/`S256ChallengeOption`/`VerifierOption`), ClickHouse
ReplacingMergeTree + FINAL, Next.js static SPA, `github.com/oauth2-proxy/mockoidc`
for the automated e2e, a real Keycloak realm for the manual check.

**Conventions that bind every task** (same as Plan A):
- Handlers return `error`; `handle()` in `hub/internal/api/errors.go` maps to HTTP.
- Storage: handlers depend on `storage.Store` only; SQL lives in `hub/internal/storage/clickhouse/`; fakes over mocks (`storagetest.Fake`).
- Mutable state = ReplacingMergeTree + read FINAL + tombstone deletes.
- Commits: conventional (`feat(hub): …`), **no AI co-author trailer** (AI_POLICY.md).
- Run `cd hub && go test ./...` and `go vet ./...` before every commit.

```go
package auth

import (
	"fmt"

	"gopkg.in/yaml.v3"
)

// GroupMap is one IdP-group → role-on-projects rule.
type GroupMap struct {
	Group    string
	Role     Role
	Projects []string
}

// OIDCConfig is the hot-reloadable OIDC configuration (auth.oidc in values).
// ClientSecret is injected from a mounted secret, never from the YAML body.
type OIDCConfig struct {
	Issuer          string
	ClientID        string
	ClientSecret    string
	GroupsClaim     string // default "groups"
	Mapping         []GroupMap
	DefaultRole     Role
	DefaultProjects []string
	ForceSSO        bool
}

// rawOIDC mirrors the YAML shape (roles as strings, validated on parse).
type rawOIDC struct {
	Issuer      string `yaml:"issuer"`
	ClientID    string `yaml:"clientId"`
	GroupsClaim string `yaml:"groupsClaim"`
	Mapping     []struct {
		Group    string   `yaml:"group"`
		Role     string   `yaml:"role"`
		Projects []string `yaml:"projects"`
	} `yaml:"mapping"`
	DefaultRole     string   `yaml:"defaultRole"`
	DefaultProjects []string `yaml:"defaultProjects"`
	ForceSSO        bool     `yaml:"forceSSO"`
}

// ParseOIDCConfig validates the mounted YAML and pairs it with the secret.
func ParseOIDCConfig(body []byte, clientSecret string) (*OIDCConfig, error) {
	var r rawOIDC
	if err := yaml.Unmarshal(body, &r); err != nil {
		return nil, fmt.Errorf("oidc config: %w", err)
	}
	if r.Issuer == "" || r.ClientID == "" {
		return nil, fmt.Errorf("oidc config: issuer and clientId are required")
	}
	c := &OIDCConfig{
		Issuer: r.Issuer, ClientID: r.ClientID, ClientSecret: clientSecret,
		GroupsClaim: r.GroupsClaim, DefaultProjects: r.DefaultProjects, ForceSSO: r.ForceSSO,
	}
	if c.GroupsClaim == "" {
		c.GroupsClaim = "groups"
	}
	for i, m := range r.Mapping {
		role, ok := ParseRole(m.Role)
		if !ok {
			return nil, fmt.Errorf("oidc config: mapping[%d]: unknown role %q", i, m.Role)
		}
		if m.Group == "" {
			return nil, fmt.Errorf("oidc config: mapping[%d]: group is required", i)
		}
		c.Mapping = append(c.Mapping, GroupMap{Group: m.Group, Role: role, Projects: m.Projects})
	}
	if r.DefaultRole != "" {
		role, ok := ParseRole(r.DefaultRole)
		if !ok {
			return nil, fmt.Errorf("oidc config: unknown defaultRole %q", r.DefaultRole)
		}
		c.DefaultRole = role
	}
	return c, nil
}
```

```go
// MapGroups turns a user's IdP groups into grants. Every project listed on a
// matched rule becomes one grant; when NO rule matches, the defaultRole is
// granted on defaultProjects (possibly none). Deduplicated by (scope, role).
func (c *OIDCConfig) MapGroups(groups []string) []Grant {
	inGroups := make(map[string]bool, len(groups))
	for _, g := range groups {
		inGroups[g] = true
	}
	var out []Grant
	seen := make(map[string]bool)
	add := func(scope string, role Role) {
		k := scope + "|" + string(role)
		if !seen[k] {
			seen[k] = true
			out = append(out, Grant{Scope: scope, Role: role})
		}
	}
	matched := false
	for _, m := range c.Mapping {
		if inGroups[m.Group] {
			matched = true
			for _, p := range m.Projects {
				add(p, m.Role)
			}
		}
	}
	if !matched && c.DefaultRole != "" {
		for _, p := range c.DefaultProjects {
			add(p, c.DefaultRole)
		}
	}
	return out
}
```

```go
// ExternalIdentity is the normalized result of an OIDC login.
type ExternalIdentity struct {
	Subject string // stable IdP subject; the user ID for SSO users is "oidc|"+Subject
	Email   string
	Name    string
	Groups  []string
}

// SetGroupMapper installs the current OIDC group→grant mapper. The main-loop
// reloader swaps it on config change; nil means "no OIDC configured".
func (s *Service) SetGroupMapper(m func(groups []string) []Grant) { s.mapper.Store(&m) }

// mapper is an atomic pointer so identityFor can read it lock-free under load.
// (add field: mapper atomic.Pointer[func(groups []string) []Grant])

// mintSession creates a session row for u and returns the raw cookie token.
func (s *Service) mintSession(ctx context.Context, st storage.Store, userID string) (string, error) {
	token, hash, err := newToken()
	if err != nil {
		return "", err
	}
	sess := storage.AuthSession{TokenHash: hash, UserID: userID,
		CreatedAt: time.Now().UTC(), ExpiresAt: time.Now().UTC().Add(s.ttl)}
	if err := st.CreateAuthSession(ctx, sess); err != nil {
		return "", fmt.Errorf("creating session: %w", err)
	}
	return token, nil
}

// CompleteSSO upserts the SSO user (origin=oidc, groups refreshed), then mints
// the same session a local login would. Grants are NOT written here — identityFor
// derives mapped grants from the stored groups + the current mapper, so manual
// grants an admin added stay intact.
func (s *Service) CompleteSSO(ctx context.Context, ext ExternalIdentity) (string, Identity, error) {
	st, err := s.st()
	if err != nil {
		return "", Identity{}, err
	}
	uid := "oidc|" + ext.Subject
	u := storage.AuthUser{ID: uid, Email: ext.Email, Name: ext.Name,
		Origin: "oidc", OidcGroups: ext.Groups}
	// Preserve a Disabled flag an admin may have set.
	if existing, err := st.GetAuthUser(ctx, uid); err == nil {
		u.Disabled = existing.Disabled
	} else if !errors.Is(err, storage.ErrNotFound) {
		return "", Identity{}, fmt.Errorf("looking up sso user: %w", err)
	}
	if u.Disabled {
		return "", Identity{}, ErrInvalidCredentials // disabled SSO user cannot log in
	}
	if err := st.SaveAuthUser(ctx, u); err != nil {
		return "", Identity{}, fmt.Errorf("saving sso user: %w", err)
	}
	id, err := s.identityFor(ctx, st, u)
	if err != nil {
		return "", Identity{}, err
	}
	token, err := s.mintSession(ctx, st, uid)
	if err != nil {
		return "", Identity{}, err
	}
	return token, id, nil
}
```

```go
func (s *Service) identityFor(ctx context.Context, st storage.Store, u storage.AuthUser) (Identity, error) {
	grants, err := st.ListAuthGrants(ctx, u.ID)
	if err != nil {
		return Identity{}, fmt.Errorf("listing grants: %w", err)
	}
	id := Identity{UserID: u.ID, Email: u.Email, Name: u.Name}
	for _, g := range grants {
		if r, ok := ParseRole(g.Role); ok {
			id.Grants = append(id.Grants, Grant{Scope: g.Scope, Role: r})
		}
	}
	// Mapped grants from the current OIDC config (SSO users only). Manual grants
	// above take precedence via RoleFor's strongest-wins; duplicates are harmless.
	if m := s.mapper.Load(); m != nil && len(u.OidcGroups) > 0 {
		id.Grants = append(id.Grants, (*m)(u.OidcGroups)...)
	}
	return id, nil
}
```

```go
package auth

import (
	"context"
	"fmt"

	"github.com/coreos/go-oidc/v3/oidc"
	"golang.org/x/oauth2"
)

// StartURL bundles the redirect URL with the PKCE verifier the caller must
// stash in a short-lived cookie for the callback.
type StartURL struct {
	URL      string
	Verifier string
}

// OIDCProvider wraps go-oidc discovery + oauth2 for one issuer/client.
type OIDCProvider struct {
	oauth       oauth2.Config
	verifier    *oidc.IDTokenVerifier
	groupsClaim string
}

// NewOIDCProvider performs OIDC discovery against cfg.Issuer.
func NewOIDCProvider(ctx context.Context, cfg *OIDCConfig, redirectURL string) (*OIDCProvider, error) {
	provider, err := oidc.NewProvider(ctx, cfg.Issuer)
	if err != nil {
		return nil, fmt.Errorf("oidc discovery: %w", err)
	}
	return &OIDCProvider{
		oauth: oauth2.Config{
			ClientID: cfg.ClientID, ClientSecret: cfg.ClientSecret,
			Endpoint: provider.Endpoint(), RedirectURL: redirectURL,
			Scopes: []string{oidc.ScopeOpenID, "profile", "email", "groups"},
		},
		verifier:    provider.Verifier(&oidc.Config{ClientID: cfg.ClientID}),
		groupsClaim: cfg.GroupsClaim,
	}, nil
}

// Start builds the authorization-code URL with state, nonce and PKCE.
func (p *OIDCProvider) Start(state, nonce string) StartURL {
	verifier := oauth2.GenerateVerifier()
	url := p.oauth.AuthCodeURL(state,
		oidc.Nonce(nonce),
		oauth2.S256ChallengeOption(verifier),
	)
	return StartURL{URL: url, Verifier: verifier}
}

// Exchange completes the flow: swap the code, verify the ID token, check the
// nonce, and extract claims into an ExternalIdentity.
func (p *OIDCProvider) Exchange(ctx context.Context, code, verifier, nonce string) (ExternalIdentity, error) {
	tok, err := p.oauth.Exchange(ctx, code, oauth2.VerifierOption(verifier))
	if err != nil {
		return ExternalIdentity{}, fmt.Errorf("code exchange: %w", err)
	}
	rawID, ok := tok.Extra("id_token").(string)
	if !ok {
		return ExternalIdentity{}, fmt.Errorf("no id_token in response")
	}
	idTok, err := p.verifier.Verify(ctx, rawID)
	if err != nil {
		return ExternalIdentity{}, fmt.Errorf("verify id_token: %w", err)
	}
	if idTok.Nonce != nonce {
		return ExternalIdentity{}, fmt.Errorf("nonce mismatch")
	}
	// Claims: email + name are standard; groups live under the configured claim.
	var claims map[string]any
	if err := idTok.Claims(&claims); err != nil {
		return ExternalIdentity{}, fmt.Errorf("decode claims: %w", err)
	}
	ext := ExternalIdentity{Subject: idTok.Subject}
	ext.Email, _ = claims["email"].(string)
	if n, ok := claims["name"].(string); ok {
		ext.Name = n
	} else {
		ext.Name = ext.Email
	}
	ext.Groups = stringSlice(claims[p.groupsClaim])
	return ext, nil
}

// stringSlice coerces a claim value ([]any of strings, or a single string) to
// []string — IdPs differ on how they encode a single-group membership.
func stringSlice(v any) []string {
	switch t := v.(type) {
	case []any:
		out := make([]string, 0, len(t))
		for _, e := range t {
			if s, ok := e.(string); ok {
				out = append(out, s)
			}
		}
		return out
	case []string:
		return t
	case string:
		return []string{t}
	}
	return nil
}
```

```go
package api

import (
	"net/http"
	"time"
)

const (
	oidcStateCookie    = "avuru_oidc_state"
	oidcNonceCookie    = "avuru_oidc_nonce"
	oidcVerifierCookie = "avuru_oidc_verifier"
)

// handleOIDCStart begins the authorization-code flow: random state+nonce in
// short-lived HttpOnly cookies (bound to the browser, not server state), a PKCE
// verifier alongside, then 302 to the IdP.
func (a *API) handleOIDCStart(w http.ResponseWriter, r *http.Request) error {
	p := a.cfg.OIDC()
	if p == nil {
		return badRequest("OIDC is not configured")
	}
	state, nonce := auth.NewID(), auth.NewID()
	start := p.Start(state, nonce)
	setShortCookie(w, r, oidcStateCookie, state)
	setShortCookie(w, r, oidcNonceCookie, nonce)
	setShortCookie(w, r, oidcVerifierCookie, start.Verifier)
	http.Redirect(w, r, start.URL, http.StatusFound)
	return nil
}

// handleOIDCCallback validates state, exchanges the code, and starts a session.
func (a *API) handleOIDCCallback(w http.ResponseWriter, r *http.Request) error {
	w.Header().Set("Cache-Control", "no-store")
	p := a.cfg.OIDC()
	if p == nil {
		return badRequest("OIDC is not configured")
	}
	state, err := r.Cookie(oidcStateCookie)
	if err != nil || state.Value == "" || state.Value != r.URL.Query().Get("state") {
		return forbidden("invalid or missing OIDC state")
	}
	nonce, _ := r.Cookie(oidcNonceCookie)
	verifier, _ := r.Cookie(oidcVerifierCookie)
	ext, err := p.Exchange(r.Context(), r.URL.Query().Get("code"), cookieVal(verifier), cookieVal(nonce))
	if err != nil {
		return unauthorized() // opaque: bad code / verify failure / nonce mismatch
	}
	token, _, err := a.cfg.Auth.CompleteSSO(r.Context(), ext)
	if err != nil {
		return err
	}
	clearShortCookie(w, r, oidcStateCookie)
	clearShortCookie(w, r, oidcNonceCookie)
	clearShortCookie(w, r, oidcVerifierCookie)
	setSessionCookie(w, r, token, int(a.cfg.Auth.SessionTTL()/time.Second))
	http.Redirect(w, r, "/", http.StatusFound) // land in the SPA, now authenticated
	return nil
}
```

- [ ] **Step 1: Implement the loader** (mirror `hub/cmd/hub/alerting.go`)

`hub/cmd/hub/oidc.go` loads `AVURUOPS_AUTH_OIDC_CONFIG` (a mounted YAML path) and
`AVURUOPS_AUTH_OIDC_CLIENT_SECRET` (from a secret), polls the file for changes,
and on each successful load: (a) `ParseOIDCConfig`, (b) `NewOIDCProvider`
(discovery), (c) atomically swaps both the `*OIDCProvider` and `*OIDCConfig`
behind functions, and (d) `authSvc.SetGroupMapper(cfg.MapGroups)`. A bad reload is
logged and the previous value kept (same discipline as `groups.go`). When the env
var is unset, OIDC stays nil and the mapper stays nil — local-only.

```go
// startOIDC returns accessor funcs for the API Config; nil funcs when unset.
func startOIDC(ctx context.Context, authSvc *auth.Service, redirectURL string) (
	provider func() *auth.OIDCProvider, settings func() *auth.OIDCConfig) {
	path := os.Getenv("AVURUOPS_AUTH_OIDC_CONFIG")
	if path == "" {
		return nil, nil
	}
	secret := os.Getenv("AVURUOPS_AUTH_OIDC_CLIENT_SECRET")
	var pptr atomic.Pointer[auth.OIDCProvider]
	var sptr atomic.Pointer[auth.OIDCConfig]
	load := func() error {
		body, err := os.ReadFile(path)
		if err != nil {
			return err
		}
		cfg, err := auth.ParseOIDCConfig(body, secret)
		if err != nil {
			return err
		}
		p, err := auth.NewOIDCProvider(ctx, cfg, redirectURL)
		if err != nil {
			return err
		}
		pptr.Store(p)
		sptr.Store(cfg)
		authSvc.SetGroupMapper(cfg.MapGroups)
		return nil
	}
	if err := load(); err != nil {
		slog.Error("initial OIDC config load failed, OIDC disabled until fixed", "path", path, "error", err)
	}
	go pollReload(ctx, path, load, "oidc") // shared helper with alerting/groups
	return pptr.Load, sptr.Load
}
```
